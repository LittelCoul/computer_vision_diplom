# Оборудование робота

## 1. Общая схема платформы

Робот представляет собой колёсную платформу с поворотным механизмом и двухосевой
камерой. Управление построено на трёх вычислительных узлах:

- **Orange Pi 3 LTS** — центральный узел, обрабатывает видео и принимает команды по сети;
- **Arduino Uno R3** — управляет двигателями, сервоприводами и считывает энкодер;
- **Персональный компьютер (Windows 11)** — пульт оператора с видеопотоком и панелью режимов.

## 2. Двигатели и механизмы

### 2.1 Двигатель движения с энкодером JGB37-520R30-12

| Параметр | Значение |
| :--- | :--- |
| Тип | Коллекторный двигатель постоянного тока с редуктором |
| Напряжение | 12 В |
| Редуктор | 30:1 |
| Энкодер | Магнитный квадратурный, 11 импульсов на оборот вала двигателя (≈330 импульсов на оборот колеса) |
| Назначение | Привод ведущих колёс, движение вперёд/назад |
| Драйвер | L298N (пины ENA, IN1, IN2) |

Энкодер используется для одометрии: подсчёт импульсов позволяет оценивать
пройденное расстояние и контролировать скорость.

### 2.2 Рулевой сервопривод LG-1501MG

| Параметр | Значение |
| :--- | :--- |
| Тип | Аналоговый сервопривод с металлическими шестернями |
| Напряжение | 5–6 В |
| Угол поворота | 0–180° (рабочий диапазон ограничен 45–135°) |
| Назначение | Поворот колёс влево/вправо |
| Пин управления | D12 Arduino |

**Рабочий диапазон углов:**

| Угол | Положение колёс |
| :---: | :--- |
| 45° | Право |
| 90° | Прямо |
| 135° | Лево |

Ограничение диапазона защищает механику от упора в крайние положения.

### 2.3 Двухфазный шаговый двигатель 28BYJ-48

| Параметр | Значение |
| :--- | :--- |
| Тип | Биполярный/униполярный шаговый двигатель |
| Напряжение | 5–12 В |
| Шаг | 64 шага на оборот (в полношаговом режиме) |
| Назначение | Вспомогательный механизм (поворотный узел, подача и т.п.) |
| Драйвер | ULN2003 |
| Пины управления | A0, A1, A2, A3 Arduino |

Управление — полношаговый режим (2 фазы одновременно), 200 шагов на команду
по умолчанию.

### 2.4 Сервоприводы камеры 2DOF (SG90 / MG90S)

| Параметр | Значение |
| :--- | :--- |
| Тип | Микросервоприводы |
| Напряжение | 5 В |
| Угол поворота | 0–180° |
| Назначение | Pan (горизонталь) и Tilt (вертикаль) камеры |
| Пины управления | D13 (pan), D11 (tilt) |

Камера может поворачиваться в пределах 0–180° по обеим осям с шагом 10°.

### 2.5 Камера

| Параметр | Значение |
| :--- | :--- |
| Тип | USB-камера (UVC) |
| Определяется как | `/dev/video1` (MJPG/YUYV), `/dev/video0` (NV12/ST12) |
| Разрешение | 1280×720 @ 30 fps (MJPG), 640×480 @ 15 fps (YUYV) |
| Назначение | Видеопоток для оператора и (в перспективе) компьютерного зрения |

## 3. Питание

| Потребитель | Параметры блока питания |
| :--- | :--- |
| Orange Pi 3 LTS | 5 В / 3 А (Type-C) |
| Arduino Uno | 9 В / 0.5–0.6 А (Jack 5.5×2.1 мм, центральный плюс) |
| Сервоприводы | 5 В / 3 А (отдельный БП или UBEC 5V 3A от 12 В) |
| Двигатели и шаговый мотор | 12 В / 3 А (Mean Well LRS-35-12 или аналог) |

**Обязательное условие:** все земли (GND) блоков питания, Arduino, драйверов
и Orange Pi должны быть соединены. Силовые потребители (двигатели, сервы)
питаются от отдельных блоков, а не через плату Arduino.

## 4. Распиновка Arduino Uno

| Устройство | Пины |
| :--- | :--- |
| Энкодер A / B | D2 / D3 (аппаратные прерывания) |
| Драйвер мотора ENA / IN1 / IN2 | D6 / D7 / D8 |
| Рулевое серво | D12 |
| Шаговый двигатель IN1–IN4 | A0 / A1 / A2 / A3 |
| Серво камеры pan / tilt | D13 / D11 |
