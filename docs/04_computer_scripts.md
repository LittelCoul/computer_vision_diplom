# Python-скрипты на компьютере

## 1. Назначение

Программа на компьютере (Windows 11) — это пульт оператора. Она показывает
видеопоток с камеры робота, перехватывает нажатия клавиш и отправляет
команды на Orange Pi по TCP. Также она позволяет переключаться между
ручным и автоматическим режимами.

## 2. Файл `manual_control.py`

### 2.1 Зависимости

| Библиотека | Назначение | Установка |
| :--- | :--- | :--- |
| `opencv-python` | Декодирование JPEG-кадров | `pip install opencv-python` |
| `numpy` | Работа с массивами | `pip install numpy` |
| `keyboard` | Глобальный перехват клавиш | `pip install keyboard` |
| `pillow` | Конвертация кадров для Tkinter | `pip install pillow` |

### 2.2 Основные параметры

| Параметр | Значение |
| :--- | :--- |
| `ORANGE_PI_IP` | IP-адрес Orange Pi (например, `192.168.1.38`) |
| `PORT` | `5000` |
| `CAM_STEP` | `10` (шаг поворота камеры) |
| Начальные углы камеры | `cam_pan = 90`, `cam_tilt = 90` |

### 2.3 Структура программы

1. **Подключение к Orange Pi** — TCP-сокет на порт 5000.
2. **`send_command(cmd)`** — отправка ASCII-строки на Orange Pi.
3. **`receive_video()`** — поток приёма видео:
   - чтение 4 байт размера кадра;
   - чтение самого JPEG-кадра;
   - декодирование через `cv2.imdecode`;
   - сохранение последнего кадра в общую переменную `latest_frame`
     (защищено `frame_lock`).
4. **`manual_control_loop()`** — поток ручного управления:
   - отслеживание состояния клавиш (`keyboard.is_pressed`);
   - отправка команды только в момент нажатия (без повторов);
   - автостоп при отпускании `W`/`S` (отправка `Z`);
   - управление камерой клавишами `8/2/4/6` с шагом 10°.
5. **`auto_mode_loop()`** — поток автоматического режима (заготовка:
   движение вперёд с паузами; заменяется на алгоритм объезда/слежения).
6. **GUI на Tkinter:**
   - слева — `Label` с видеопотоком (обновление каждые 30 мс);
   - справа — панель с кнопками **«Ручное управление»** и
     **«Автоматическое управление»**, а также подсказка по клавишам.
7. **Завершение** — по закрытию окна или ESC: отправка `Z`,
   установка `stop_event`, корректное закрытие сокета.

### 2.4 Клавиши управления

| Клавиша | Действие | Отправляемая команда |
| :---: | :--- | :--- |
| W | Вперёд | `W` |
| S | Назад | `S` |
| A | Колёса влево | `A` |
| D | Колёса вправо | `D` |
| Z | Стоп колёс | `Z` |
| C | Колёса прямо | `C` |
| Q | Шаговый вперёд | `Q` |
| E | Шаговый назад | `E` |
| 8 | Камера вверх | `CAM,<pan>,<tilt-10>` |
| 2 | Камера вниз | `CAM,<pan>,<tilt+10>` |
| 4 | Камера влево | `CAM,<pan-10>,<tilt>` |
| 6 | Камера вправо | `CAM,<pan+10>,<tilt>` |
| ESC | Выход | `Z` |

### 2.5 Режимы работы

- **Ручной** — клавиши активны, команды уходят на Orange Pi.
- **Автоматический** — клавиши игнорируются, работает `auto_mode_loop()`.
  Переключение — кнопками на правой панели.

### 2.7 Известные ограничения

- Глобальный перехват клавиш через `keyboard` требует прав администратора  
    на некоторых системах Windows.
    
- Видео и команды идут по одному TCP-соединению: при потере пакетов  
    возможны артефакты на видео.
    
- Автоматический режим пока реализован как заготовка и требует  
    алгоритмического наполнения (объезд препятствий, слежение за объектом,  
    движение по линии и т.п.).
