# Python-скрипты на Orange Pi

## 1. Назначение

Orange Pi 3 LTS выполняет роль сервера: принимает команды от компьютера по TCP,
передаёт их в Arduino по UART и отправляет видеопоток обратно на компьютер.

## 2. Файл `manual_control_orange.py`

### 2.1 Зависимости

| Библиотека | Назначение | Установка |
| :--- | :--- | :--- |
| `pyserial` | Работа с UART | `sudo apt install python3-serial` |
| `opencv-python` | Захват и кодирование видео | `sudo apt install python3-opencv` |
| `numpy` | Работа с массивами кадров | `sudo apt install python3-numpy` |

### 2.2 Основные параметры

| Параметр | Значение |
| :--- | :--- |
| `HOST` | `0.0.0.0` (слушать все интерфейсы) |
| `PORT` | `5000` |
| `ARDUINO_PORT` | `/dev/ttyACM0` |
| `BAUD` | `9600` |
| Камера | `/dev/video1`, MJPG, 640×480 |

### 2.3 Структура программы

1. **Подключение к Arduino** — открытие `/dev/ttyACM0` на скорости 9600,
   пауза 2 секунды для перезагрузки платы.
2. **Инициализация камеры** — `cv2.VideoCapture('/dev/video1', cv2.CAP_V4L2)`,
   формат MJPG, разрешение 640×480.
3. **`send_to_arduino(cmd)`** — отправка строки в Arduino с переводом строки.
4. **`handle_client(socket)`** — поток приёма команд от компьютера:
   - `W` → `M,200,0`
   - `S` → `M,200,1`
   - `A` → `S,135`
   - `D` → `S,45`
   - `Q` → `T,200,1`
   - `E` → `T,200,0`
   - `Z` → `M,0,1`
   - `C` → `S,90`
   - `CAM,<pan>,<tilt>` → `C,<pan>,<tilt>`
5. **`stream_video(socket)`** — поток отправки видео:
   - чтение кадра с камеры;
   - кодирование в JPEG (качество 70);
   - отправка 4 байт размера + самого кадра;
   - обработка `BrokenPipeError`, `ConnectionResetError`, `OSError`;
   - закрытие сокета в `finally` (единственное место закрытия).
6. **Главный блок** — создание TCP-сервера, ожидание одного клиента,
   запуск двух потоков (`handle_client` и `stream_video`).

### 2.4 Особенности реализации

- **Только один клиент.** Сервер рассчитан на одно подключение
  (`server.listen(1)` и `server.accept()`). Для нескольких операторов
  потребуется доработка.
- **Сокет закрывается только в `stream_video`.** Это устраняет ошибку
  `Bad file descriptor`, которая возникала при закрытии сокета в `handle_client`.
- **Порт Arduino** может отличаться (`/dev/ttyUSB0` для клонов с CH340).
  Проверяется командой `ls /dev/ttyACM* /dev/ttyUSB*`.

### 2.5 Запуск

```bash
cd ~/computer_vision_diplom/OrangePI
python3 manual_control_orange.py
```
Если появляется `Permission denied` на порт Arduino:

```bash
sudo usermod -a -G dialout $USER
```

и перезайти в систему.

### 2.6 Известные ограничения

- Видеопоток и команды идут по одному TCP-соединению: при плохом канале  
    возможны задержки видео.
    
- Скорость UART 9600 бод ограничивает частоту команд (для плавного  
    слежения в будущем можно поднять до 115200).
