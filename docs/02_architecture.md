# Взаимосвязь устройств

## 1. Общая схема
```
┌─────────────────────┐ TCP/IP (Wi-Fi/Ethernet)          ┌─────────────────────┐
│ Компьютер (Windows) │◄────────────────────────────────►│ Orange Pi 3 LTS     │
│ manual_control.py   │ команды + видеопоток (порт 5000) │  manual_control_    │
│                     │                                  │   orange.py         │
└─────────────────────┘                                  └──────────┬──────────┘
                                                                    │ UART / USB
                                                                    │ (/dev/ttyACM0)
                                                                    ▼
                                                         ┌─────────────────────┐
                                                         │ Arduino Uno R3      │
                                                         │ robot_full.ino      │
                                                         └──────────┬──────────┘
                                                                    │
                           ┌────────────────┬────────────────┬──────┴───────┐
                           ▼                ▼                ▼              ▼
                           Драйвер L298N Рулевое серво Шаговый мотор Сервы камеры
                           (движение) (LG-1501MG) (ULN2003) (pan/tilt)
```

## 2. Роли устройств

### 2.1 Компьютер (Windows 11)

- **Роль:** пульт оператора.
- **Функции:**
  - отображение видеопотока с камеры Orange Pi в окне Tkinter;
  - перехват нажатий клавиш (W/S/A/D/Q/E/Z/C/8/2/6/4);
  - отправка команд на Orange Pi по TCP;
  - переключение режимов «ручной / автоматический».

### 2.2 Orange Pi 3 LTS

- **Роль:** посредник между компьютером и Arduino, источник видеопотока.
- **Функции:**
  - TCP-сервер на порту 5000;
  - приём команд от компьютера и преобразование их в строки для Arduino;
  - передача команд в Arduino через UART (`/dev/ttyACM0`);
  - захват видео с `/dev/video1` и отправка кадров (JPEG) обратно на компьютер.

### 2.3 Arduino Uno R3

- **Роль:** - контроллер исполнительных механизмов.
- **Функции:**
  - управление драйвером L298N (движение);
  - управление рулевым серво (поворот колёс);
  - управление шаговым двигателем через ULN2003;
  - управление сервами камеры (pan/tilt) с плавным движением;
  - подсчёт импульсов энкодера через аппаратное прерывание.

## 3. Протокол обмена

### 3.1 Компьютер ↔ Orange Pi (TCP, порт 5000)

Команды передаются как ASCII-строки без перевода строки.

| Команда | Значение |
| :--- | :--- |
| `W` | Вперёд |
| `S` | Назад |
| `A` | Колёса влево (135°) |
| `D` | Колёса вправо (45°) |
| `Z` | Стоп колёс |
| `C` | Колёса прямо (90°) |
| `Q` | Шаговый вперёд (200 шагов) |
| `E` | Шаговый назад (200 шагов) |
| `CAM,<pan>,<tilt>` | Поворот камеры (0–180° по обеим осям) |

Видеопоток передаётся в обратном направлении: сначала 4 байта размера кадра
(big-endian), затем JPEG-кадр.

### 3.2 Orange Pi ↔ Arduino (UART, 9600 бод)

| Команда | Значение |
| :--- | :--- |
| `M,<speed>,<dir>` | Мотор: speed 0–255, dir 0/1 (0 — назад, 1 — вперёд) |
| `S,<angle>` | Рулевое серво: 45–135° |
| `T,<steps>,<dir>` | Шаговый: количество шагов, направление |
| `C,<pan>,<tilt>` | Камеры: 0–180° по обеим осям |
| `E` | Запрос значения энкодера |
| `R` | Сброс счётчика энкодера |

Ответы Arduino: `OK ...` при успехе, `ERR ...` при ошибке, `ENC,<значение>`
при запросе энкодера.

## 4. Порядок запуска системы

1. Подать питание на Orange Pi (5 В / 3 А), дождаться загрузки.
2. Подать питание на Arduino (9 В) и драйверы (12 В).
3. На Orange Pi запустить: `python3 manual_control_orange.py`.
4. На компьютере запустить: `python manual_control.py`.
5. Убедиться, что в окне появился видеопоток, и выбрать режим управления.

## 5. Сетевые адреса

| Устройство | Адрес |
| :--- | :--- |
| Orange Pi | `192.168.1.38` (пример; уточняется командой `hostname -I`) |
| Компьютер | Получает адрес по DHCP в той же подсети |
| Порт TCP-сервера | 5000 |
